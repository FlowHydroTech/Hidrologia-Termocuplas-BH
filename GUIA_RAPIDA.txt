  GUIA RAPIDA — VFLUX2 Python · Hidrologia Termocuplas BH

Proyecto : Estimacion de flujos verticales de agua subterranea
           Rio Cuncumen / Silala
Metodo   : Hatch-Amplitude (2006)
Sensores : iButton DS1922L en 5 termocuplas (TC1-TC5)
Entrega  : Marzo 2026

================================================================================
  1. REQUISITOS
================================================================================

  - Python 3.12 o superior
  - uv (gestor de paquetes) — instalar con: pip install uv
    o desde https://docs.astral.sh/uv/getting-started/installation/
  - Windows 10/11, Linux o macOS
  - ~500 MB de espacio en disco (incluyendo entorno virtual)

================================================================================
  2. INSTALACION
================================================================================

  2.1 Descomprimir el archivo ZIP en la carpeta de trabajo.

  2.2 Instalar dependencias y crear entorno virtual:

      Desde la raiz del proyecto:

        cd Hidrologia-Termocuplas-BH
        uv sync

      Esto crea automaticamente el entorno virtual .venv, instala todas
      las dependencias de pyproject.toml (numpy, pandas, scipy, matplotlib,
      plotly, folium, pyproj, openpyxl) y el paquete local "vfluxx".

      El archivo uv.lock garantiza versiones reproducibles.

      Alternativa sin uv (pip manual):
        python -m venv .venv
        .venv\Scripts\activate       (Windows)
        source .venv/bin/activate     (Linux/Mac)
        pip install -r requirements.txt
        pip install -e .

================================================================================
  4. EJECUCION — 3 MODOS DISPONIBLES
================================================================================

  MODO A — Python puro (el mas simple)
  -------------------------------------

  Ejecuta las 11 etapas del pipeline sin servidor ni dashboard:

      python scripts/run_pipeline.py

    Con uv: uv run python scripts/run_pipeline.py


  MODO B — Prefect + Dashboard interactivo
  -----------------------------------------

  Requiere dos terminales:

      Terminal 1: prefect server start
      Terminal 2: python scripts/prefect_pipeline.py

    Dashboard disponible en: http://localhost:4200

    Flags opcionales:
      --no-figs    Omitir generacion de figuras
      --no-html    Omitir paneles HTML
      --no-server  No verificar servidor Prefect


  MODO C — Docker (contenedores)
  -------------------------------

  Requiere Docker Desktop instalado y en ejecucion.

      docker compose up                    # Completo (pipeline + dashboard)
      docker compose run --rm standalone   # Solo pipeline Python puro
      docker compose up prefect            # Solo dashboard Prefect

    Dashboard Docker: http://localhost:4200


  PIPELINE: 11 ETAPAS
  --------------------

   #  | Etapa          | Descripcion
  ----+----------------+----------------------------------------------
   1  | Carga          | Lectura de datos iButton (5 TC x 3 sensores)
   2  | Alineacion     | Alineacion temporal a grilla comun 10 min
   3  | Armonico       | Ajuste armonico 24 h por sensor
   4  | Flujo          | Calculo Hatch-Amplitude + McCallum
   5  | Series         | Series temporales ventana deslizante 48 h
   6  | Confiabilidad  | Indice IC por termocupla
   7  | Incertidumbre  | Bootstrap + propagacion dL, dC
   8  | IQR            | Tabla estadistica por par de sensores
   9  | Exportacion    | Excel 7 hojas + CSVs
  10  | Resumen        | Resumen ejecutivo en consola
  11a | Figuras        | 10 figuras estaticas (PNG + PDF, 300 DPI)
  11b | Paneles        | 4 paneles HTML interactivos
